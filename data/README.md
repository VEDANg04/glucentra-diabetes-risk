# Dataset

This project uses the **BRFSS 2015** health indicators dataset (CDC survey, 253,680 records).

1. Download `diabetes_012_health_indicators_BRFSS2015.csv` from
   [Kaggle: Diabetes Health Indicators Dataset](https://www.kaggle.com/datasets/alexteboul/diabetes-health-indicators-dataset).
2. Place it in this folder, so the path is
   `data/diabetes_012_health_indicators_BRFSS2015.csv`.

The CSV is not committed to the repo (see `.gitignore`).
